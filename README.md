🎯 FEATURES AT A GLANCE:
────────────────────────────
🔐 Secure local login/register with profile image  
💬 Chat history auto-saved in your browser (no server used)  
🖼️ Drag & drop file/image preview in chat  
💻 Run HTML/CSS/JS code live with output panel  
🧠 AI-style chatbot behavior with voice responses  
🌐 Link previews with “Go to Link” buttons  
🧬 Website Cloner (HTML/CSS only via JavaScript)  
🎭 Hacker UI with full animations and dark theme  
📱 100% responsive: mobile, tablet, and desktop

⚠️ DOWNLOAD DANGER — READ BEFORE USING ⚠️
───────────────────────────────────────
This app runs LOCALLY — no data is sent online.  
But BE AWARE of:
• 🚨 Pasting unknown or malicious code  
• 📁 Dropping files from untrusted sources

• Saved settings ⚙️  

🛠️ INSTALLATION GUIDE:
────────────────────────────
1. 📦 Clone or download this repo  
2. 🧰 Open terminal in the project folder  
3. Run the following commands:

> npm install                     📦 Install dependencies  
> npm install vite --save-dev    🚀 Add Vite for development  
> npm run dev                    🔧 Start local dev server

🌐 Open in browser:
> http://localhost:5173
